GitHub Profile Finder

A GitHub Profile Finder is developed using HTML, CSS, JavaScript, and the GitHub REST API to search GitHub users and display their profile information, including avatar, bio, followers, following, and public repositories.

Technologies Used

HTML
CSS
JavaScript
GitHub REST API

Features

Search GitHub users by username
Display profile picture and user information
Show bio, followers, following, and public repositories count
Redirect users to the GitHub profile using the "Visit Profile" button
Input validation for empty usernames
Error handling for invalid or non-existing GitHub usernames

Tools Used

Visual Studio Code
GitHub
Web Browser (Google Chrome/Edge)

Project Structure

HTML is used to create the user interface and search functionality.
CSS is used to design a responsive and attractive user interface.
JavaScript is used to fetch real-time user data from the GitHub REST API.
The GitHub REST API is used to retrieve and display GitHub profile information dynamically.
